Bienvenue dans FLX OS !

FLX OS est un système d'exploitation libre, développé par Florynx Labs.
Conçu pour être simple, rapide et sécurisé.

Tout ce que vous voyez au-dessus du kernel Linux a été écrit de zéro :
le compositeur, le gestionnaire de fenêtres, la bibliothèque graphique,
le shell et toutes les applications.

À essayer :
  - Start (touche Win) pour chercher une application
  - Survolez le bouton maximiser pour les layouts d'ancrage
  - Alt+Tab, touches Win+Flèches pour naviguer
  - Le bouton Copilot en haut à droite
  - Terminal : tapez « proof » ou « fetch »
  - Paramètres > Personnalisation pour changer le thème et le fond d'écran

FLX OS — Plus qu'un système. Une vision.
